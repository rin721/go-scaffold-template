# 013 研究优先任务门禁

## 状态

- 任务性质：纯文档治理变更。
- 当前状态：已完成。
- 实施日期：2026-08-14。
- 确认规则：本任务最终交付物只有研究、规则和文档导航，按纯文档例外在研究与计划门禁通过后直接完成。

## 范围

本任务从 012 的结构化研究档案中提炼通用方法，把原“计划 -> 确认 -> 实施”流程升级为“研究 -> 计划 -> 确认 -> 实施”。变更只涉及 `AGENTS.md`、研究方法说明和任务级文档导航，不修改 Go 源码、配置、依赖、脚本、测试或运行行为。

## 一句话结论

所有仓库任务必须先形成可检索、可复核的研究证据，研究门禁通过后才能制定计划；非纯文档实现仍须等待用户在计划报告后的独立消息中确认，实施中新证据推翻前提时必须退回研究或计划阶段。

## 阅读顺序

1. [研究档案](research/README.md)：012 模式、当前流程差距和本任务证据。
2. [requirements.md](requirements.md)：目标、范围、约束和验收标准。
3. [design.md](design.md)：门禁状态机、档案结构、回退规则和文件影响。
4. [tasks.md](tasks.md)：任务 ID、验证证据、提交范围和剩余风险。

## 交付边界

本任务没有把“每次研究”解释为“每次都必须联网或罗列框架”。研究深度由当前问题决定，但研究顺序、当前仓库事实核验、既有档案检索、证据可追溯和事实/推断分离不可跳过。
