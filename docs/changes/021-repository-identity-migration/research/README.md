# 021 研究档案

本目录记录 GitHub 仓库改名后，本地 checkout、Go module、运行身份和文档身份的当前事实。研究只回答“哪些身份已改变、哪些仍未改变以及迁移边界是什么”，不把目标名称写成已经完成的本地实现。

## 记录

- [R001 当前仓库身份核验](R001-current-repository-identity/report.md)：核验 GitHub canonical URL、独立旧仓库、本地 remote、module/import、应用名、020 隔离验证状态和历史记录边界。
- [R002 迁移后验证](R002-post-migration-verification/report.md)：核验 canonical remote、module/import、运行品牌、历史残留和完整 Go 门禁的实施结果。
